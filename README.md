# Mayerfeld FrontEnd Practicum
This project is 4 weeks 4 assignments work to learn, practice and build a Travel Agency Website.
This project was build from base HTML, CSS to full Website with working backend.

## URL

The website can be checked here -> [https://mayerfeld-project.netlify.app/](https://mayerfeld-project.netlify.app/).

## Tech Stack

### FrontEnd
- HTML
- CSS
- React
- Tailwind

### BackEnd
- NodeJS
- Express
- PostgreSQL

### Deployement
- Netlify
- Render
- Neon
